# Lost physical device

1. Cancel active jobs and release or cancel the device's exclusive lease so the router cannot select it.
2. Revoke pairing, development, signing, and network credentials associated with the device.
3. Remove the device from approved inventories while preserving its stable target ID and last audit record.
4. Review applications, test data, logs, shared folders, and profiles that may have existed on the device. Follow the applicable disclosure policy.
5. If recovered, erase and re-enroll it; re-enable Developer Mode and DDI services only after identity and ownership verification.

Exit criteria: no active lease, no authorized pairing, no routable target, incident evidence retained, and replacement capacity confirmed.
