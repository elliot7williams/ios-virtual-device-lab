# Support

This is an independent research and development tool, not an Apple product. Use GitHub Discussions for setup and workflow questions and GitHub Issues for reproducible manager defects. Include the app version, macOS version, Mac model class, companion contract output, and a sanitized diagnostic bundle; never attach an IPSW, VM archive, credential, signing key, or unredacted personal data.

Compatibility is evidence-based. A configuration shown as experimental or unverified is not supported until its real-device-lab qualification campaign is sealed and reviewed.
